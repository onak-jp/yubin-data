# 郵便番号データ（OnAK版）

日本郵便の郵便番号データを、そのまま使える形に整えたものです。

**ダウンロード：** 右の「Releases」から最新版のZIPを取得してください。
説明ページ：https://onak.co.jp/yubin/

## 収録内容

- 一般の住所　126,083行
- 事業所の個別郵便番号　22,424件
- 7桁の郵便番号（ハイフン付きの列もあり）、旧5桁の郵便番号、全国地方公共団体コード
- ふりがな（日本郵便のデータにある範囲）
- 全データに市外局番
- 末尾00の番号（「以下に掲載がない場合」）の印
- 頭がそろう町名（例：江戸川区の「一之江」と「一之江町」）の印
- 町域の括弧書きを整理（丁目・番地などの条件、ビルの階、列挙された地名を別の列に）

## ファイル

| ファイル | 内容 |
|---|---|
| onak_yubin_YYYYMM.csv | 一般の住所（UTF-8） |
| onak_yubin_YYYYMM_sjis.csv | 一般の住所（Shift_JIS） |
| onak_yubin_jigyosyo_YYYYMM.csv | 事業所（UTF-8） |
| onak_yubin_jigyosyo_YYYYMM_sjis.csv | 事業所（Shift_JIS） |

CSV形式です。Excelでファイルを直接開くと、郵便番号などの先頭の0が消えます。「郵便番号（ハイフン付き）」の列を使うか、Excelの「データ」→「テキストまたはCSVから」で、文字列として読み込んでください。

## 元にしたデータ

- 日本郵便「郵便番号データ」
- 総務省「市外局番の一覧」

各版の元データの日付は、Releases の説明に書いています。
